# 🎰 Экспресс 37 - Telegram Game

Игра в стиле рулетки для Telegram бота.

## 🚀 Быстрый старт

### Демо (без сервера)
Откройте `docs/index.html` в браузере - игра будет работать в демо-режиме с балансом 10,000₽

### Полная версия с Telegram ботом

1. Задеплойте папку `bot/` на Railway
2. В Railway добавьте переменную окружения `BOT_TOKEN`
3. Обновите `API_URL` в `docs/js/game.js`
4. Включите GitHub Pages для папки `docs/`
